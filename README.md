# LibraryHub

## Project Description
LibraryHub is a simple library management system developed for Software Quality Engineering lab practice.

## Objectives
- Practice Git and GitHub.
- Manage software defects using GitHub Issues.
- Create test plans and test cases.
- Apply Equivalence Partitioning and Boundary Value Analysis.
- Perform unit testing using pytest.

## Project Structure
- `src/` - Source code
- `tests/` - Unit tests
- `docs/` - Project documentation
- `screenshots/` - Lab evidence

## Technologies
- Python
- Git
- GitHub
- pytest

## Testing
Unit tests will be written using pytest.
